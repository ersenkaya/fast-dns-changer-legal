2. What the app does

DNS Changer lets you choose which DNS resolver your device uses. It uses Android's VpnService API to redirect only DNS traffic (port 53) to the server you select — it does not route, inspect, or proxy your general internet traffic. You can select from a built-in list of DNS providers or add your own custom DNS servers.
